# Harness 流水线豁免记录

> 记录所有跳过 S3 编译检查或放宽 S4.5 收敛闸门的 case。
> 格式：`YYYY-MM-DD-简短描述.md`
> 定期 review（每月一次），长期无效的豁免应被收回。

## 豁免级别说明

| 级别 | 含义 | 适用场景 |
|------|------|---------|
| `S3_SKIP` | 跳过 S3 编译检查（tsc） | 修复历史编译错误任务，改完后 S5 仍会完整验证 |
| `S45_WIDE` | 放宽 S4.5 复杂度收敛 |  legitimately 复杂的业务逻辑，无法进一步简化 |
| `S1_SHORTCUT` | 跳过 S1 全局审视 | 仅限纯配置/文档改动，不涉及源码 |

## 使用规则

1. 调用 `harness_run_flow` 时传入 `exempt_files` 或 `skip_s3_compile: true`，必须在同会话内创建豁免记录
2. 豁免记录必须在 24 小时内创建，否则视为违规
3. 每次 review 时检查：豁免是否仍然必要？是否已促成架构改进？
