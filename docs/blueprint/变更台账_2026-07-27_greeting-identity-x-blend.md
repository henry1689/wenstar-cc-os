# WenStarOS 变更台账 — X 类留存原始身份标签

> **流程**: S1→S2→S3→S4→S5→S7 | **日期**: 2026-07-27 | **风险**: 🟢 低

## 根因

EntityGreetingProtocol 的 `_describeIdentity` 和 `_greet` 使用线性 if-else 链：A→B→G→X→默认。当实体从 A/B 升级为 X 后，`category='X'` 跳过原始分类分支，丢失"家人"/"同事"等原始身份。

## 修复

| 函数 | 修复 |
|:---|:---|
| `_greet` | X 类检测 relation 中的家族词 → A 式亲切 + X 式亲近 |
| `_describeIdentity` | X 类检测 relation 中的家族词 → "家人，有多次亲密互动" |
